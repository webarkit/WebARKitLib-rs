WebARKitLib.rs – NFT Tracking Example

This demo demonstrates AR2 Natural Feature Tracking running entirely in Rust/WASM. The AR2 tracking engine uses template matching on image pyramids to refine a camera pose.

The pipeline loads .iset (image pyramid) and .fset (feature points) marker data, accepts an initial 3×4 camera pose, and runs per-frame tracking to produce a refined pose.

Note: Full NFT detection (KPM) requires a pure-Rust FREAK feature matcher (Phase C). This demo focuses on the tracking stage which is already 100% Rust.
